# 구구단 산성비 게임 🏰

초등학교 2학년 학생들을 위한 곱셈구구 학습 게임입니다.

## 게임 소개

곱셈 문제를 풀어 성을 지키는 타워 디펜스 스타일의 교육 게임입니다. 재미있게 구구단을 학습할 수 있습니다.

## 주요 기능

- **스토리 모드**: 단계별로 레벨을 클리어하며 진행
- **연습 모드**: 원하는 단을 집중적으로 연습
- **챌린지 모드**: 제한 시간 내 최대한 많은 문제 풀기
- **난이도 선택**: 초급(2-5단), 중급(2-7단), 고급(2-9단)
- **실시간 피드백**: 정답/오답에 대한 즉각적인 피드백
- **통계 추적**: 점수, 정답률, 콤보 등 게임 통계

## 기술 스택

- React 18
- TypeScript
- Vite
- CSS3

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 빌드 미리보기
npm run preview
```

## 게임 방법

1. 게임 모드와 난이도를 선택합니다
2. 화면에 나타나는 곱셈 문제를 풀어주세요
3. 정답을 입력하면 적이 물리쳐집니다
4. 오답이거나 시간 초과 시 적이 성에 도달합니다
5. 성의 체력이 0이 되면 게임 오버입니다

## 게임 조작

- 숫자 키패드 또는 화면 터치로 답 입력
- 키보드 숫자 키로도 입력 가능
- Enter 키로 답 제출
- Backspace 키로 지우기
- ESC 키로 전체 지우기

## GitHub Pages 배포

이 프로젝트는 GitHub Pages에 자동으로 배포됩니다.

### 배포 방법

1. GitHub에 저장소를 생성합니다
2. `vite.config.ts`의 `base` 경로를 저장소 이름에 맞게 수정합니다
3. 코드를 GitHub에 푸시합니다
4. 저장소 Settings > Pages에서 GitHub Actions를 선택합니다
5. 자동으로 배포됩니다!

자세한 내용은 [DEPLOY.md](./DEPLOY.md)를 참고하세요.

### 배포된 사이트

배포가 완료되면 다음 형식의 URL에서 확인할 수 있습니다:
```
https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/
```
